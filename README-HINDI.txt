इस पैक में सभी फाइलें एक ही root folder में हैं ताकि मोबाइल से GitHub पर अपलोड करना आसान हो।

1) index.html — आपकी मौजूदा वेबसाइट और हर eBook पर 🔗 शेयर करें बटन।
2) share-<slug>.html — हर eBook का अलग पेज, जिसमें Facebook/WhatsApp Open Graph जानकारी है।
3) ebook-<slug>-preview.jpg — हर eBook की शेयर प्रीव्यू इमेज।

GitHub पर: esybay01-eng/GyanHub1 repository खोलें → Add file → Upload files → इस ZIP को पहले मोबाइल में Extract करें → Extract किए गए folder की सभी 15 फाइलें चुनकर अपलोड करें। फाइलें repository के मुख्य root में ही रहें, किसी नए folder के अंदर नहीं। फिर Commit changes करें।
